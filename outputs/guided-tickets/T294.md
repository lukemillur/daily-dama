### Direction A — Quiet native list

Native stack header with large title "Tricks", header search, ＋ (Define new trick) and ⋯ (Goals, Notes, Laced tricks). Grouped inset sections with a short uppercase rank header plus laced progress. One-line rows: number or laced ✓, bold name, quiet meta line (laces, notes, goals), trailing focus circle; tap toggles focus. Row actions move to swipe (right: Practice; left: Notes, Goals) and a long-press context menu (Practice, focus, Notes, Goals, Trick history; Edit and Delete for custom tricks).

```
Tricks                         ⋯  ＋
[⌕ Search tricks              ]
FOCUSED · 2
 ✓  Pull up spike            ◉
    12 laces · 2 notes
RANK 1 · BASIC · 3RD CLASS   4 / 5
 ✓  Big cup                  ○
 04 Moshikame x5     ◀ [Notes][Goals]
```

- Gains: densest list, shortest build, brand carried by type and accent.
- Costs: gestures are hidden; each needs a VoiceOver custom action; web needs a visible ⋯ fallback.
- Rough build: 3 tickets (header + search; row redesign; swipe + context actions).

### Direction B — List plus trick detail

Same header, search and sections as A. Rows lose inline actions and get a chevron; a leading circle toggles focus. New route `/app/tricks/[trickId]`: Practice, focus toggle, laced stats, latest notes and goals, recent seshes; custom Edit/Delete in its ⋯ menu. Row context menu keeps quick Practice.

```
‹ Tricks                          ⋯
Pull up spike
[Rank 1 · Basic · 3rd class · #05]
[ ▶ Practice ] [ ✓ Focused ]
 12 laces | 4 seshes | 7 best/2 min
NOTES · 2                      All ›
GOALS · 1                      All ›
RECENT SESHES             History ›
```

- Gains: every action visible without gestures (better for VoiceOver and web); a home for the visualizer and per-trick history.
- Costs: Practice takes two taps (or a long-press); overlaps `stats/[trickId]` and needs a merge-or-link decision; new dynamic route needs web direct-navigation and rewrite checks.
- Rough build: 4–5 tickets.

### Direction C — Rank ladder

Native header as in A, plus a segmented control: Focused / Ladder / Custom. Each rank is a collapsible rung with a laced progress bar; the first rank not fully laced opens by default. Rows inside are A's compact rows with A's actions. Header search flattens to a cross-rank result list.

```
[ Focused | Ladder | Custom ]
 1  Basic · 3rd class      5 / 5 ✓  ██████
 2  Basic · 2nd class      4 / 5    █████░
 3  Basic · 1st class      1 / 5 ⌃  █░░░░░
    01 Frying pan, Spike   ◉
    02 Around the block    ○
 4  Advanced · 3rd class   0 / 5
```

- Gains: most Kentei-specific; screen becomes a progress view; short at rest.
- Costs: browsing across ranks takes taps; new UI state (segment, open rung) to own; overlaps Home/Stats as a progress surface; still gesture-dependent.
- Rough build: 4 tickets.

All three keep the custom-trick and rank invariants unchanged (name snapshots, radio rank picker, custom tricks after standard tricks at the same rank, unranked Custom section).
