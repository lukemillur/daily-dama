- `src/app/app/profile/index.tsx`: Profile is a `KeyboardAwareScroll` with `scrollEnabled={!pickerDragging}`; `ThemeColorPicker` reports drag state through `onDragStateChange`. This is the mechanism the spectrum case must exercise.
- `src/features/profile/components/color-spectrum-picker.tsx`: two responder surfaces (saturation/lightness, hue) labelled `"<prefix> saturation and lightness"` and `"<prefix> hue"`, using `onStartShouldSetResponder`/`onMoveShouldSetResponder`/`onResponderTerminate`.
- Streak field: label "Streak threshold in minutes", valid = whole integer 1..60 (`isValidStreakThresholdMinutes`), `maxLength={2}`, `number-pad`, error text "Enter a whole number from 1 to 60.", Save disabled unless valid and changed. Expected invalid inputs: empty and `0` (also try `00`). Note `"1."` parses to 1 (valid); `number-pad` may allow `.`; record what actually happens rather than judging.
- Profile entry points: "Start Kentei assessment" (`/app/profile/kentei-assessment`) and "Send feedback" (`/feedback`). Open the feedback form, check it renders and Back/exit works; never press its submit. If the form has a submit that could transmit, leave fields empty or do not type anything that could be sent.
- Five tabs: Home, Sesh, Tricks, Stats, Profile (layout in `src/app/app/_layout.tsx`).

## Step 1. Driving input and judging gesture validity

- Taps/keys/text: `adb shell input tap`, `input text`, `input keyevent`. State via `adb exec-out uiautomator dump /dev/tty` (or dump to file and pull into the scratchpad) and `adb exec-out screencap -p` for screenshots.
- Page scrolling: `input swipe x1 y1 x2 y2 500` (duration >= 300 ms; T322 found real swipes scroll).
- Spectrum dragging needs a continuous single-pointer gesture with intermediate MOVE events. Use `adb shell input motionevent DOWN x y`, several `MOVE` steps (with small `sleep 0.05`), then `UP` (available API 31+; confirm it works on API 37). A plain `input swipe` can also be used but delivers few MOVE events; prefer `motionevent`.
- Validity control (do this first, record it): prove the tool can produce a real drag before attributing any result to the app. (a) Page-scroll control: a `motionevent` or swipe starting on non-picker content (e.g. the Daily streak copy) scrolls the Profile page. (b) Tap control: tap inside the hue/saturation surface and confirm the displayed hex/contrast readout changes (taps exercise the same responder). Only if (a) and (b) work is a motionevent drag a valid instrument. If the tool cannot produce MOVE events that move the page in control (a), the spectrum case is "inconclusive: tool invalid" and must NOT be recorded as an app failure; try an alternative (a longer motionevent sequence, `adb shell cmd input` variants, or `adb emu` console touch events) and record what was tried. If no valid instrument exists, T324 stays Blocked on tooling, not on a defect.
- Spectrum pass criteria: dragging on the saturation/lightness surface and on the hue slider, with vertical-ish motion across the page-scroll axis, changes the color readout continuously, ends with the page scroll position unchanged (compare a stable element's bounds before/after), and a subsequent swipe outside the picker scrolls the page again (scroll re-enabled after `onResponderRelease/Terminate`). Also test a drag that exits the surface bounds mid-gesture and an interrupted gesture (UP outside), then confirm scrolling is not stuck disabled. Test at both viewports.

2. Custom colors: change custom color(s) via picker (taps and, once valid, drags; also typed hex entry if the picker has one: try one valid and one invalid hex and note feedback). Confirm contrast ratio readouts update.

6. Kentei assessment entry and return: tap Start Kentei assessment, confirm the screen renders, Android Back returns to Profile with scroll sensible, and header back (if any) too. Do not change rank or mark tricks laced; if the screen only presents a ladder, do not interact beyond viewing.

Complete or skip the first-run tutorial through TalkBack's own UI as needed.

## Risks

- Dev-tools floating button overlays the right edge (about x 900-1030, y 1400-1530) and may intercept taps (T322); scroll the target clear of it.
- Launching the URL into a running activity crashes the dev client; always `force-stop` first.
- `wm size/density` persist across reboots if not reset; always reset and verify, including on error paths.
- TalkBack left enabled makes user 10 hard to drive and affects later sessions; restoration is mandatory.
- Do not accidentally act on user 0 (check `am get-current-user` before each major phase).
- Do not tap anything in AccountSection (sign-up/sign-in/delete) or feedback submit.
