# T074 — Use compact back navigation in multi-trick setup

## Goal

Replace the large first-step multi-trick setup back button with the compact back-to-parent treatment already used by the trick-specific Stats route, while preserving navigation to `/sesh`. Keep the timing setup step's separate `Back to trick selection` action unchanged.

## Ordered implementation plan

1. Update `src/features/sesh/components/multi-trick-sesh-entry.tsx` selection-step navigation.
   - Replace the first-step `ExitBackButton`/large `Button` treatment with a compact text-link-style control matching `src/app/stats/[trickId].tsx`'s authoritative `BackLink` treatment: leading left arrow, underlined compact typography, and link accessibility semantics.
   - Preserve the existing `useRouter().replace('/sesh')` callback so the control returns to the canonical Sesh home rather than changing the wizard state model or introducing a new route abstraction.
   - Reuse an existing UI primitive/style only if it can match the Stats treatment without changing unrelated button behavior; otherwise add the smallest local styled text/pressable treatment in the multi-trick entry component. Do not modify the timing-step `BackButton`, its `Back to trick selection` accessibility label, or its local state transition.

2. Extend `src/features/sesh/components/multi-trick-sesh-entry.test.tsx` with focused component coverage.
   - Mount the first-step route harness and assert the compact action is exposed with the established back-navigation label/accessibility semantics (including the leading-arrow visible label and link role expected by the Stats treatment).
   - Press that action and assert `mockReplace` receives exactly `/sesh`, and that the Sesh home picker is rendered.
   - Continue into timing setup and assert `Back to trick selection` remains available and returns to the trick-selection step, proving the two back actions remain distinct.

3. Verify the focused test and the repository's required web-safe checks.
   - Run `yarn test --runInBand src/features/sesh/components/multi-trick-sesh-entry.test.tsx` (or the repository-equivalent Jest invocation if the configured script does not accept a path).
   - Run `yarn lint` and `yarn tsc --noEmit`.
   - Run `yarn expo export --platform web --output-dir /tmp/daily-dama-web-export` if the component/style change requires the normal web export check; do not perform native validation because native hardening is deferred.

## Scope and assumptions

- This is a visual/navigation refinement only; the `MultiTrickSeshEntryStep` union and all Sesh state transitions remain unchanged.
- The Stats route's `← Back to Stats` `BackLink` is the source of truth for compact copy, visual treatment, and accessibility role. The analogous multi-trick copy is `← Back to Sesh`.
- No new shared button variant is warranted for this single local treatment unless inspection during implementation reveals an existing shared compact-link primitive.
- `TASKS.md` is already claimed for T074; the implementation stage should update its status/history according to the ticket workflow, not as part of this planning-only change.
