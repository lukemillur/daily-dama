# T285 plan: recompose trick directory rows for phone widths

Scope: presentation only, one component (`src/features/tricks/components/trick-directory.tsx`, `TrickRow` and its styled pieces) plus its test. All consumers (Tricks route, `all-trick-goals-screen`, `multi-trick-sesh-entry`, `onboarding-selection-step`) render this one component, so fixing it fixes them all. No change to props, trick identity, selection ownership, snapshots, persistence, or sync. Web only; the simulator check is deferred (AGENTS.md "Active platform scope"). T284 is deferred, so there is nothing to coordinate with.

## Root cause (verified in source)
`TrickRowContainer`/`ActivatableTrickRowContainer` is a single `flex-direction: row` holding: `identityElement` (`identityLayout`: `min-width: 180px; flex: 1; padding 15px 22px; gap 18px`, with a 26px Position column), then `RowActions` (up to 5 x min 48px + 4px gaps, `padding-right: 12px`), then `SelectionIndicatorButton` (about 55px wide). On a 320-390px viewport the name column only gets what remains (about 60-110px), so the name wraps to about 6 lines. The Position column and 22px padding also eat width.

## Design
Compact layout when the window is narrow: two stacked bands inside the row.
1. Identity band (full width): Position, name (full remaining width), meta line (Custom label / laces), and the selection checkbox indicator at the right end. Selection and identity stay on the first, fastest-to-hit band.
2. Action band (below, indented to align with the name column via `padding-left` equal to the Position column plus gap, or left-aligned): Notes, Goals, Practice, Edit, Delete, in a `flex-wrap: wrap` row so labels never overflow horizontally (custom tricks have 5 actions; at 320px they wrap onto a second line, which is acceptable and avoids overflow).
Wide layout (>= breakpoint) stays exactly as today (single row), so desktop web behaviour is preserved.

Breakpoint: add `const COMPACT_ROW_MAX_WIDTH = 600` in the component file (the row sits in a column of at most 760px; 600 keeps tablets/desktop single-row behavior while switching before the name column collapses). Do not reuse the 768 constant used by `shouldPinSelectionChrome`; this one is about row content width, and a comment should say why. Measure with `useWindowDimensions()` called once in `TrickDirectory`, derive `isCompact`, and pass it as a `compact` prop to `TrickRow` (and include it in `SectionList` `extraData`, otherwise rows will not re-render on resize/rotation). Avoid per-row hooks.

## Implementation steps
1. Add `compact?: boolean` to `TrickRowProps`; compute in `TrickDirectory`; add to `extraData`.
2. Restructure `TrickRow` JSX without changing handlers or accessibility props:
   - Keep `identityElement` and `selectionIndicatorElement` and `rowActionsElement` as separate elements (already are). Non-compact render order unchanged: identity, actions, indicator.
   - Compact render: `TrickRowContainer` with `$compact` switching `flex-direction` to `column; align-items: stretch`, containing `CompactIdentityLine` (row: identityElement flex 1 + selectionIndicatorElement) followed by `rowActionsElement` when `hasRowActions`. Take care: `identityElement` is a sibling Pressable (checkbox role) to the indicator Pressable; keep them as siblings, not nested.
   - `identityLayout`: make `min-width: 180px` conditional (drop it when compact, `min-width: 0`), reduce horizontal padding to about 16px and gap to 12px when compact; `TrickIdentity` gets `flex: 1; min-width: 0` so long words wrap inside the column instead of overflowing. Add `flex-shrink: 1` on `TrickName`.
   - `RowActions` compact variant: `flex-wrap: wrap; align-self: stretch; padding: 0 12px 8px <name-column-offset>`. Keep `RowAction` `min-width: 48px; min-height: 44px` unchanged (exit criteria: targets not reduced). Do not shrink font sizes.
   - `ItemSeparator` has `margin-left: 66px`; reduce to match compact Position offset only if visually misaligned (check in browser); keep it simple.
   - Pass `$compact` to styled components via transient props (`$compact`), consistent with the file's convention.
3. `ActivatableTrickRowContainer` (goal picker) is a Pressable wrapping everything; the same compact structure applies. Nested action Pressables already `stopPropagation`; leave the documented `Link asChild` Practice gap untouched.
4. Keep the Practice `Link asChild` element and all `accessibilityLabel`s byte-identical (existing tests key off them).
5. Update `ARCHITECTURE.md`/docs only if it describes row layout (grep for "RowActions"/"trick row"; likely nothing). Mark T285 done in `TASKS.md` per the project convention in the closing commit (the executing agent's normal flow), noting the simulator check as deferred.

- Sticky section headers (see `SECTION_BOUNDARY_HEIGHT` comment) interact with taller rows; verify scrolling at the boundary is no worse.

- Do not alter selection/`onToggle` semantics or the Practice link seam.
