## iOS Simulator acceptance (iPhone 17e, iOS 27.0; `yarn ios` dev build)
Prereq: local Supabase running (`supabase/README.md`), `.env` with `EXPO_PUBLIC_SUPABASE_URL=http://127.0.0.1:54321` and the local publishable key, app rebuilt/restarted so env is inlined. Check rows with local DB, e.g. `psql` against local Postgres: `select id, name, message, email, created_at from api.feedback order by created_at desc limit 5;`.
1. Guest: fresh/signed-out app, Profile -> Send feedback -> submit a message. Expect success screen, one new row, `email` is null.
2. Signed in: sign in with an existing verified local user via password (sign-up is not needed or available; create the user via Supabase Studio/Mailpit or an existing account), reopen /feedback, submit. Expect one new row with `email` = account address.
3. Network unavailable (concrete, achievable): with the app on the form and a message typed, stop local Supabase (`supabase stop`, or stop just the API/Kong container with `docker stop supabase_kong_<project>`), then submit. The simulator shares the host network, so 127.0.0.1:54321 refuses the connection and the insert rejects, hitting `mapNetworkError`. Expect the existing error copy "Something went wrong sending your feedback. Please try again." and the typed message and name still in the fields; then restart Supabase and tap submit again to confirm retry works (one extra row). Alternative if preferred: relaunch with `EXPO_PUBLIC_SUPABASE_URL` pointed at an unused port, e.g. `http://127.0.0.1:1`. Do not use Simulator airplane mode - the simulator has no per-device network toggle (Network Link Conditioner is host-level and needs owner setup), and a device-wide toggle is not reliably achievable by the agent. This criterion is therefore agent-verifiable by stopping Supabase; no owner step is required unless the dev build cannot be rebuilt.
4. Record Android checks as not run (no verified Android dev build).
If the simulator or local Supabase cannot be run in the implementer's environment, mark those criteria as not run and hand to owner; never record as passed.
