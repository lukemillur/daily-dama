## 1. Row structure: centre position and checkbox on the whole row (items 1, 2)
Current: in compact mode the row is a column: `CompactIdentityLine` (Position + name, then indicator) above `RowActions`. Position lives inside the identity Pressable, so it can only centre on the name line.

Change the compact layout to: row, `align-items: center` containing three siblings:
1. `Position` (lifted out of `identity`; fixed `min-width: 26px`, decorative, no longer part of the toggle press target. Its text is already excluded from the checkbox `accessibilityLabel`).
2. A body column (`flex: 1; min-width: 0`) holding the identity Pressable/View (name + meta) and `RowActions` beneath.
3. `selectionIndicatorElement` (checkbox), vertically centred by the row's `align-items: center`.

Wide layout (>= 600 px) is already a centred row `[identity][actions][indicator]`; lift `Position` out the same way so both modes share one structure (body = identity only in wide, actions remain a sibling). Keep wide layout visually unchanged apart from the padding trims below. Drop `CompactIdentityLine` if it becomes unused. Update the "Compact padding-left aligns..." comment: with Position as its own column, the action band no longer needs the 54px left padding hack; it aligns by construction with the body column.

Laced rows: `border-left-width: 4px` is on the row container, so Position keeps the same left padding in both states. Give the row container `padding-left` fixed and let the 4 px border shift content; to keep the number column aligned with and without the border, either use `padding-left: calc(16px - border)` equivalent via `$laced ? 12px : 16px` on Position's wrapper, or always reserve 4 px (`border-left-width: 4px; border-left-color: transparent` when not laced). Prefer the always-reserve option (simplest, guarantees alignment) and then drop `Position` left padding to 12px. Verify alignment with laced and non-laced rows adjacent.

A11y: the checkbox-role Pressable (`SelectableIdentity`) and `SelectionIndicatorButton` keep their labels/roles/state. Add `importantForAccessibility="no-hide-descendants"`/`accessibilityElementsHidden` on `Position` only if the existing tests or VoiceOver show it as a stray element; otherwise leave it.
