## Step 0 - Confirm the header API against the INSTALLED version (blocker check)
Docs (docs.expo.dev/router/advanced/stack) list: `Stack.Title large`, `Stack.Header`, `Stack.Toolbar placement=...` (alpha), and the options `headerSearchBarOptions` (`placeholder`, `onChangeText`, `onCancelButtonPress`, `hideWhenScrolling`, `placement`, `autoCapitalize`, `tintColor`, `textColor`, `barTintColor`) and `headerLargeTitleEnabled` (docs page also shows `headerLargeTitle` - the two names conflict). The docs fetch did NOT show `Stack.SearchBar`, or Toolbar menu / icon / accessibilityLabel props. Before coding, read `node_modules/expo-router/build/**/*.d.ts` and `@react-navigation/native-stack` types for: (a) large-title option name, (b) `headerSearchBarOptions` shape, (c) how to build a header button with an accessibility label and a native menu (candidates: `Stack.Toolbar` + `Stack.Toolbar.Menu`/`MenuAction` if present; `unstable_headerRightItems` with `type:'menu'`/`'button'` items and `accessibilityLabel`; fallback: `headerRight` with `Pressable`s and an in-app menu). Prefer the first that exists with typed accessibility labels and a real native menu on iOS. Record the choice in the PR description. If no installed API gives labelled buttons plus a menu, stop and report rather than adding a dependency.

## Step 1 - `TrickDirectory`: one route-level prop for native chrome
In `trick-directory.tsx` add `readonly nativeHeader?: true` (name per T312 note: one prop, no `Platform.OS` inside the file). When set:
- `directoryHeader` is not rendered (`ListHeaderComponent` undefined; the `TextField` is therefore never rendered even if `search` is passed - `search` still drives filtering and the "No tricks match" empty state).
- `SectionList` gets `contentInsetAdjustmentBehavior="automatic"` so iOS large-title collapse and safe-area inset work and no row sits under the status bar.
Default (prop absent) output must be byte-for-byte the same. Add a model/component test in the existing trick-directory test file: with `nativeHeader` + `search.query='cup'`, only matching names render and no "Search tricks" field; with empty query, Focused and rank sections render.

- Native search bar `onChangeText` receives an event (`nativeEvent.text`) in react-native-screens/react-navigation; the Expo docs example shows a string. Match installed types.
- A transparent/large header with `SectionList` needs `contentInsetAdjustmentBehavior="automatic"`; sticky section headers must still pin below the collapsed header - check on device.
- `Screen` uses `edges={['left','right']}`; on native the header now owns the top inset, so keep that and confirm no double inset.
- Do not alter `TrickDirectory` default output: it also serves goal picker and Sesh picker (existing tests must stay green).
