# T311 plan: no autocorrect in any text field

## Findings (verified against branch HEAD 4af49fe)
- `src/components/ui/text-field.tsx` spreads `...props` onto `Input` after its own props, so a caller can override. Defaults go BEFORE `{...props}` (destructure nothing new; just add `autoCorrect={false} spellCheck={false}` ahead of the spread). Keep the existing `autoComplete` numeric default untouched.
- Every `TextField` caller (tricks search at `src/app/app/tricks/index.tsx:257`, custom-trick name, notes, goals, feedback, profile, sesh, onboarding, trick-directory, auth) inherits the default, so those need no edits. Auth screens already pass `autoCorrect={false}`; leave them (the repo guard allows `false`).
- Raw `TextInput`s that do NOT use `TextField`: only two, both `styled(TextInput)`:
  - `StepInput` in `src/app/app/tricks/index.tsx:562` (used at :277)
  - `DurationInput` in `src/features/sesh/components/sesh.tsx:1322` (used at :438, :455)
- The task entry names `color-spectrum-picker.tsx`, but it contains no `TextInput` (only comments mentioning one; the hex field is a `TextField` in `theme-color-picker.tsx`). No change there. Mention this in the PR/TASKS note.

## Steps

2. Raw inputs: add `.attrs({ autoCorrect: false, spellCheck: false })` to `StepInput` and `DurationInput` (styled-components/native `.attrs` is already used in text-field.tsx; attrs are overridable by props, which the guard test covers). Do not touch autoCapitalize.

   - New repo guard `src/shared/forms/no-autocorrect.test.ts` (node fs walk of `src/`, skip `*.test.*`): for each `.tsx` file, find JSX tags `<TextField`, `<TextInput`, and any `styled(TextInput)` / `styled(TextField)` / `Input` wrappers; fail on `autoCorrect={true}`, bare `autoCorrect` (boolean shorthand), `autoCorrect="..."`, `spellCheck={true}`/bare `spellCheck`.
